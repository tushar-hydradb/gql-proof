# grammar

the digital artifacts published with iso/iec 39075:2024 (gql), unmodified, from https://standards.iso.org/iso-iec/39075/ed-1/en/ under the iso customer licence

- `ISO_IEC_39075(en).bnf.xml` is the grammar, used by the generator
- `ISO_IEC_39075(en).bnf.txt` is the same grammar as readable bnf
- `ISO_IEC_39075(en)-features.xml` is the optional feature ids, for tagging coverage per feature later
