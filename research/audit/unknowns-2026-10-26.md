# the unknowns audit (2026-10-26)

> for agents: every source of the type checker's unknown (`Ty::Any`), open record
> (`Record(None)`) and unit-less duration (`Duration(None)`) in `src/verify/types.rs`,
> classified. the claim's H1 says the unknown type comes only from the environment;
> this is the list that backs it.

an independent agent read `src/verify/types.rs` at 94ac64b. it ran an instrumented
copy over every `sentences/*.jsonl` sentence (10,481 distinct) and about 130 probes.
sites are named by function and arm.

classes:
- **a**: after a violation is reported, so the tree is withheld anyway
- **b**: an operation over an unknown input, so the unknown is H1's
- **c**: the environment itself (H1)
- **d**: a type the sentence fixes, typed as unknown. these are the defects
- **unreachable**: the grammar always gives the child that is looked up, and no
  sentence or probe reached the site

## the (d) sites and what was done

| site | probe that passed | rule broken | fix |
|---|---|---|---|
| `ty`, `element_id function` | `MATCH ( x ) RETURN ELEMENT_ID ( x ) AS e NEXT RETURN COALESCE ( e , 1 ) AS a , e \|\| 'x' AS b` | 20.10 SR 3 reading (ID076) | `Ty::Opaque`: `ty` checks every element id function, binding variable reference, property reference and value query typed so with `opaque_ok` |
| `for_statement`, `Ty::Table` with no procedure body | `TABLE t = { RETURN 1 AS a } FOR r IN t RETURN r . b AS c` | 20.11 SR 2 a | `Ty::Table(Option<Fields>)`: a table variable, a declared binding table type and a nested query carry their columns |
| `for_statement`, `_ => Any` with a dynamic source | `FOR x IN CAST ( NULL AS ANY ) RETURN COALESCE ( x , 1 ) AS a` | 22.19 SR 2 (strict) | the element of a dynamic source is dynamic |
| `for_statement`, `_ => Any` with a null source | `FOR x IN NULL RETURN x + 1 AS a , x \|\| 'a' AS b` | 14.8 SR 10 a gives no type | refused: `14.8 SR 10 null` (gate-only) |
| `concatenation`, list concatenation of two null operands | `FOR x IN NULL \|\| NULL RETURN x + 1 AS a` | 20.15 SR 2 gives no element type | refused: `20.15 SR 2 null` (gate-only); a dynamic operand gives dynamic elements |
| `ty`, `duration function` with mixed or no record fields | `RETURN DURATION ( { years : 1 , days : 1 } ) + DURATION ( 'PT1S' ) AS d` | 20.28 SR 1 | moot: every record argument is refused (`NoDurationRecord`, `20.28 SR 1 record`, the seventeenth review) |
| `arithmetic_of`, duration term `x * NULL` | none | none: Duration(None) is stricter than the text's null type | none |

probes for each fix are in `tests/probes_checker.rs`, in `unknowns_audit_element_id`
and `unknowns_audit_rows_and_elements`.

## the other sites

- **c**: a dynamic parameter; a session parameter S does not set; a binding
  variable reference not in the environment, which is an unbound name (the
  scope checker reports it) or a named procedure's columns with no YIELD;
  `yield_columns` for a named procedure; a FOR over a catalog table or a table
  parameter.
- **b**: `combine` with an unknown input (the known inputs are still combined);
  a unary sign, TRIM list, numeric or instant arithmetic over an unknown; two
  unit-less durations; `kept`; the wild property arm.
- **a**: the composite column after 22.19 SR 2 or 14.2 SR 10; a FOR over a body
  with no result (11.2 SR 2); the factor error arm (20.21 SR 3); the arithmetic
  no-operator and 20.28 SR 1 arms; the concatenation and `combined` error arms;
  `value_query` after 20.6 SR 3, 20.6 SR 8 or 9.1 SR 7; the property arms for a
  missing field or property, Unfollowed, Null and a non-element; the
  category-primary arm with other than one definition, and the default `_` arm.
  every origin the corpus produced was on a tree already flagged.
- **faithful**: `RECORD` / `ANY RECORD` with no field spec, the text's open
  record; a property over an open record giving `ANY` (20.11 SR 2 b); the
  `PROPERTY_COMPONENTS` duration, which is no expression type.
- **unreachable**: the parameter value fallbacks; FOR with no source; `ty` on a
  token; the general value specification else arm; a parenthesized expression
  with no inner; let, record field, modulus and substring with missing parts;
  the graph or table reference with no primary; `argument` with no arguments;
  the final arms of `arithmetic_of` and `concatenation`; `case_abbreviation`,
  `cast` and `aggregate` fallbacks; `shape` and `table_fields` fields with no
  value type; the `value_type` default arm (50 value types probed).

## gaps

- the instrumented trace logged a missing name per sentence, not per tree. the
  claim that no sentence-bound name is lost rests on targeted probes. these
  covered NEXT, YIELD, CALL, OPTIONAL CALL, OPTIONAL MATCH, LET, FOR, ORDINALITY,
  INSERT, VALUE, LET .. IN, and RETURN and ORDER BY aliases. SELECT .. FROM loses
  names, but 14.12 SR 27 always reports it.
- `Ty::Number`, numeric with exact or approximate left to the implementation,
  was not audited.
- `Ty::Graph` carries no graph type. a graph's type is followed only where a
  rule asks, and those places are readings in the audit rows (10.1 SR 8).
